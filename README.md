Project Overview
=============================================================================================================
This project presents an interactive Credit Card Transaction Analysis Dashboard developed using Microsoft Power BI.

The objective of the project is to analyze credit card transaction data and identify important patterns in revenue, transaction volume, transaction amount, interest earned, card category, expenditure type, customer job, education level, and transaction channels.

The dashboard provides a consolidated view of transaction performance and helps identify the major contributors to revenue and customer transaction activity.

Project Objective.
==================================================================================================
*Main objectives*
* Analyze overall credit card transaction performance.
* Identify revenue contribution by card category.
* Analyze quarterly revenue and transaction volume.
* Identify the most important expenditure categories.
* Understand revenue contribution by customer occupation.
* Analyze revenue by education level.
* Compare transaction channels such as Swipe, Chip, and Online.
* Identify high-performing customer and transaction segments.
* Create an interactive dashboard for business decision-making.
